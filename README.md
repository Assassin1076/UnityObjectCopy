Unity Object Copy API
这是一个高度实验性的API插件，它提供了一种在Unity运行时中复制一个物体但是完全避免激活它的方法。
该API能够保证被克隆的物体上的所有组件都不会触发Awake/OnEnable/Start等生命周期方法。

这个插件使用了一种高度精巧的构造方法来实现对原生层函数的调用，换言之，它是一个超级石山，高度依赖于特定版本的UnityPlayer.dll，因此请保证你确实正在使用这个指定版本的UnityPlayer.dll。
要注意的是，本插件还大量使用这个特定版本的UnityPlayer.dll中的字节流/偏移等用作特征，有可能在不同的构建中发生变化，请注意报错信息。

这个插件使用了大量的unsafe代码，请确保你完全理解了unsafe代码的风险。
